# Agent instructions

## Writing

- Run `/unslop:unslop` on commit messages, code comments and messages to the dev.
- Commit messages and code comments trade grammar for brevity. Drop articles and filler words when meaning survives. This overrides unslop's rule against over-compression, but only for commits and comments.

## Code comments

- Ask before adding a comment to code. Show the comment text and wait for the dev to approve it.
